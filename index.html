Selected projects

  • AutomationAnsible · VMware · Jira

    Full virtual machine lifecycle with Ansible

    My internship project at Beneva. Getting a virtual machine meant waiting for system administrators to build it by hand with scripts. Now a Jira form triggers an Ansible workflow that delivers a ready-to-use Linux or Windows machine in VMware, and a second form deletes it when it is no longer needed.

    After

  • AutomationHashiCorp Vault · SSH · AAP

    Signed SSH certificates with HashiCorp Vault

    On the team running Ansible Automation Platform, the automation service accounts reached virtual machines with static SSH keys: highly privileged, hard to track, and hard to rotate. I automated SSH key signing with HashiCorp Vault. No static key is deployed any more, only certificates issued by the internal Vault.

    Before
    Static SSH keys
    After
    Vault-signed certificates

  • KubernetesEKS · Helm · GitHub Actions · AWS

    Ephemeral namespaces on EKS

    I worked on the project that built ephemeral namespaces for EKS. A GitHub Actions workflow creates a namespace and deploys developers’ Helm charts straight into it. After 48 hours at most it is gone, so nothing lingers in the clusters. We also automated the AWS access entries that connect each team’s repositories to the clusters it deploys to.
